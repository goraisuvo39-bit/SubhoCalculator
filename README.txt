SUBHO CALCULATOR - Android Studio project

Features:
- Basic arithmetic and parentheses
- Scientific keys: sin, cos, tan, log, square root, square, pi, percent
- Backspace and clear
- Uploaded audio extracted from all 3 MP4 files
- Sound rotation on every key press: sound1 -> sound2 -> sound3 -> sound1 ...
- Only one sound is played per key press; sounds are never played together.

IMPORTANT:
This environment does not have the Android SDK / Gradle installed, so an installable APK could not be compiled here. To build the APK:
1. Open this folder in Android Studio.
2. Allow Gradle sync and install Android SDK Platform 35 if prompted.
3. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
4. Android Studio will create app/build/outputs/apk/debug/app-debug.apk.

Package: com.subho.calculator
Minimum Android: 6.0 (API 23)
